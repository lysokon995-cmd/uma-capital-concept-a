# UMA Capital — редакционный макет

Версия 27 октября 2026. Главная и 12 внутренних страниц. Вход сразу на главную страницу. Старый адрес review/ перенаправляет на главную.

## GitHub Pages

Распакуйте архив. Загрузите содержимое папки в корень одного репозитория: index.html должен быть в корне. В Settings → Pages выберите Deploy from a branch, нужную ветку и / (root). Сборка и npm не требуются. Все пути относительные, поэтому проект работает и в подпапке репозитория.

Для локального просмотра используйте статический HTTP-сервер. Открытие через file:// не поддерживает загрузку данных вкладок.
