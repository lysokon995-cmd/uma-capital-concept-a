# UMA Capital — редакционный сайт

Обновление 27 октября 2026. 12 страниц, вход сразу на главную.

## Публикация

Содержимое размещается в корне репозитория. GitHub Pages: ветка main, / (root). Сборка и npm не нужны. Пути относительные.

## Страницы

Главная; about/; properties/; три страницы БЦ; operation/; team/; contact/; documents/; privacy/; cookies/.

Отдельная страница согласия удалена. Политики отображаются полным HTML-текстом. Исходные юридические документы хранятся в рабочей папке, PDF-просмотрщика на сайте нет. Юридические тексты приведены на русском языке. Интерфейс и основные страницы переключаются RU/EN.

Контактные кнопки открывают arenda@umacapital.ru. «Запросить презентацию» добавляет тему выбранного БЦ. Форм сбора заявок нет, аналитика отсутствует.

Cookie: обязательные настройки языка и выбора конфиденциальности; необязательные карты Яндекса по умолчанию отключены. Принять/отклонить/настроить; повторное открытие из футера. Отзыв разрешения удаляет встроенные карты.

Медиа локальные. Фотографии доставляются в WebP подходящего размера; большие галереи используют реальные оригиналы, маленькие исходники не растягиваются. Видео — H.264 MP4/yuv420p, отдельные варианты для desktop/mobile, постеры. На экране ролик автоматически воспроизводится циклически; браузер может ограничивать autoplay.

Это клиентский макет. Индексация демонстрации отключена; параметры SEO для рабочего домена, миграция WordPress, 301, DNS, резервирование и серверная защита относятся к этапу переноса на основной сайт.
