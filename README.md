# UMA Capital: две концепции в одном проекте

Один репозиторий, одна стартовая страница и две интерактивные концепции.

## Просмотр
Распакуйте архив целиком и откройте index.html. На стартовой странице выберите «Архитектура» или «Редакционный». Для возврата к выбору используйте кнопку «Назад» браузера.

## Публикация на GitHub Pages
1. Создайте один репозиторий, например uma-capital-concepts.
2. Загрузите в него СОДЕРЖИМОЕ распакованного архива. Файл index.html должен находиться в корне репозитория, рядом с папками UMA-01-Architecture, UMA-02-Editorial и previews.
3. Включите GitHub Pages с публикацией из корня основной ветки.
4. Передайте клиенту главную ссылку проекта: сначала он увидит страницу выбора, затем сможет открыть любую концепцию.

Сам ZIP не нужно загружать как единственный файл: GitHub Pages публикует распакованные файлы.

## Содержимое
- index.html — стартовая страница выбора, без кнопок скачивания.
- UMA-01-Architecture/ — первая концепция, два интерфейсных цвета.
- UMA-02-Editorial/ — вторая концепция, три интерфейсных цвета.
- previews/ — изображения для стартовой страницы.
- .nojekyll — служебный файл для статической публикации.

Все видео, изображения, стили и сценарии локальны и уже включены. Дополнительная сборка или конвертация не требуется. Пути относительные, поэтому проект работает внутри GitHub Pages-репозитория. Концепции сохранены без изменений.

Основной шрифт — системная Verdana с резервным sans-serif, если Verdana отсутствует. Если браузер запрещает автозапуск видео, доступны заставка и ручной запуск.
