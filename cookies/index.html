Политика в отношении файлов cookie

1. Общие положения

1.1. Настоящая Политика в отношении файлов cookie (далее — Политика) определяет порядок и условия использования ООО «УМА Кэпитал» (далее — Общество) файлов cookie Пользователей во время их посещения и использования сайта https://umacapital.ru/ и его поддоменов (далее — Сайт).

1.2. Настоящая Политика дополняет положения документа «Политика обработки персональных данных».

1.3. Посещая Сайт и совершая акцепт настоящей Политики путем нажатия кнопки «Принять», Пользователь выражает свое согласие на использование файлов cookie на условиях, изложенных в настоящей Политике. Согласие Пользователя в соответствии с настоящей Политикой действует до тех пор, пока Пользователь не примет решение удалить сохраненные cookie и (или) ограничить (запретить) их сбор в настройках своего браузера, через который осуществляется вход на Сайт, а также в настройках своего устройства.

2. Термины и определения

2.1. Аналитический сервис — инструмент веб-аналитики, позволяющий отслеживать поведение Пользователей на Сайте.

2.2. Пользователь — посетитель Сайта, данные которого обрабатываются в соответствии с Политикой обработки персональных данных;

2.3. Сайт — совокупность графических и информационных материалов, а также программ для ЭВМ и баз данных, обеспечивающих их доступность в сети Интернет по сетевому адресу https://umacapital.ru;

2.4. Файл cookie — небольшие текстовые файлы, загружаемые на устройство (в том числе, мобильные телефоны, компьютеры, планшеты и иные устройства), с которого осуществляется вход на Сайт. Каждый раз при открытии страницы соответствующего интернет-сайта веб-клиент (браузер) Пользователя пересылает указанный текстовый файл веб-серверу в составе HTTP-запроса, чтобы предоставить такому веб-серверу информацию о действиях или предпочтениях Пользователя в Интернете. При этом для обеспечения безопасности и сохранности данных Пользователя веб-клиент (браузер) Пользователя, как правило, не передает файлы cookie, предназначенные для одного веб-сайта, другим ресурсам.

Для целей настоящей Политики, под «файлами cookie» понимаются далее также любые другие схожие технологии. По своему назначению выделяются следующие виды файлов cookie — аналитические файлы cookie, маркетинговые файлы cookie, технические файлы cookie. Подробная информация о видах используемых Обществом файлов cookie изложена в разделе 3 Политики.

3. Виды файлов cookie, используемых Обществом

3.1. Общество использует технические файлы cookie, необходимые для обеспечения базового функционирования Сайта. В частности, они позволяют пользователям перемещаться по Сайту и просматривать его содержимое, включать выбор языка, обеспечивать безопасность. Пользователь может настроить браузер таким образом, чтобы он блокировал эти файлы cookie или уведомлял пользователя об их использовании, но в таком случае возможно, что некоторые разделы Сайта не будут работать.

3.2. Состав информации, которая может содержаться в файлах cookie, зависит от используемого устройства Пользователя, программного обеспечения на устройстве Пользователя, Сайта или Приложения, с которым взаимодействует Пользователь.

3.3. При обработке файлов cookie информация о посещении Сайта не передается в Аналитические сервисы.

4. Цели использования файлов cookie

4.1. Общество может использовать файлы cookie для реализации следующих целей:

4.1.1. обеспечение полноценного и корректного функционирования Сайта;

4.1.2. обеспечение безопасности Сайта, а также выявление попыток мошенничества и злоупотребления использования полученной информацией третьими лицами.

5. Порядок использования файлов cookie

5.1. Общество вправе обрабатывать файлы cookie с использованием средств автоматизации посредством осуществления следующих действий (операций) — сбор, запись, систематизация, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передача (предоставление, доступ), обезличивание, блокирование, удаление, уничтожение.

6. Способы отказа от использования файлов cookie

6.1. Пользователь может управлять файлами cookie различными способами. Для управления файлами cookie с помощью используемых браузера или устройства, необходимо воспользоваться инструкцией, предоставляемой компанией-разработчиком браузера или производителем устройства, которые использует Пользователь.

6.2. В случае удаления или блокировки файлов cookie, возможно, не все функции Сайта будут доступны Пользователю или не все страницы Сайта будут корректно отображаться.

6.3. Большинство браузеров разрешают использование файлов cookie по умолчанию, но Пользователь может самостоятельно определить, следует ли использовать файлы cookie, с помощью элементов управления браузера, которые обычно находятся в меню «Инструменты» или «Настройки» браузера.

6.4. Пользователь может настроить параметры браузера, используемого для просмотра Сайта, чтобы включить, отключить или удалить файлы cookie. Подробные инструкции по настройке браузера опубликованы компаниями-разработчиками браузеров, и их можно найти, например, здесь:

  • Яндекс Браузер;
  • Chrome;
  • Firefox;
  • Safari for macOS;
  • Safari for iOS;
  • Opera

7. Заключительные положения

7.1. Любые изменения, внесенные в Политику, будут опубликованы на странице размещения настоящей Политики. Пересмотренная Политика вступает в силу на следующий день после ее публикации на Сайте. Продолжение использования Сайта означает согласие Пользователя с пересмотренными положениями Политики. В случае несогласия с каким-либо положением Политики, Пользователь обязан прекратить использование Сайта.
